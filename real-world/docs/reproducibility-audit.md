# Reproducibility Status

This page supersedes the preliminary packaging audit. For current instructions, start with the [real-world README](../README.md).

The package now includes observed dependency inventories, a checksummed runtime archive manifest and installer, a unified directory/environment entry point, task embeddings and poses, and end-to-end operating instructions.

The eight evaluated checkpoints and training datasets are now available with [download commands and checksums](released-assets.md). Remaining release requirements are a public workstation-runtime download location, a verified PICO APK version, the robot-side camera environment record, and clean Linux plus on-site hardware acceptance. See [distribution scope](release-scope.md) and [validation](verification.md). Do not treat offline packaging checks as proof of complete hardware reproducibility.
