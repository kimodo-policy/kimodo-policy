# Reproducibility Status

This page supersedes the preliminary packaging audit. For current instructions, start with the [real-world README](../README.md).

The package now includes observed dependency inventories, a checksummed runtime archive manifest and installer, a unified directory/environment entry point, task embeddings and poses, and end-to-end operating instructions.

Remaining release requirements are actual runtime/checkpoint distribution locations, a verified PICO APK version, the robot-side camera environment record, and clean Linux plus on-site hardware acceptance. See [distribution scope](release-scope.md) and [validation](verification.md). Do not treat offline packaging checks as proof of complete hardware reproducibility.
