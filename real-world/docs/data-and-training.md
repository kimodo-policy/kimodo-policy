# Data Semantics

| Field | Meaning |
|---|---|
| `observation.joint_q` | Measured 29-body-joint positions |
| `action.joint_q` | GMR/SONIC reference positions for 29 body joints; body supervision target |
| `control.joint_q_target` | SONIC PD joint targets |
| `observation.state` | Packed 43-dimensional measured body/hand state |
| `action.wbc` | Packed 43-dimensional body/hand target |
| `action.hand_binary` | Two hand actions: 0=open, 1=close |
| `action.hand_q` | Fourteen target hand joint angles |
| `action.root_p` / `action.root_q` | Reference root pose in the episode reference frame |
| `action.root_z` | Absolute reference pelvis height |

The 14 hand targets are generated by trigger mapping and the hand solver, not independent tracking of each finger. The current PICO mapping uses a discrete trigger branch above 0.5.

The real-world FT configuration supervises **binary actions**, conditioned on **continuous measured hand closure** projected from `observation.state`. The loader's optional continuous action mode projects `action.wbc` to two hand closure values; it does not directly supervise 14 independent hand angles. The existence of `action.hand_q` in a recording does not change the model's output contract.

The loader restores absolute root height from `action.root_z`. Unobserved global translation is represented by placeholders and feature masks; reference displacement must not be presented as measured robot position.
